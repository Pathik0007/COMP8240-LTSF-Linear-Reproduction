# Original ETTh1 Replication

## Purpose

This directory records experiments reproducing selected results from:

Ailing Zeng, Muxi Chen, Lei Zhang, and Qiang Xu,
"Are Transformers Effective for Time Series Forecasting?",
AAAI 2023.

## Initial DLinear Reproduction

The official LTSF-Linear repository was executed without tracked
source-code modifications at commit:

`0c113668a3b88c4c4ee586b8c5ec3e539c4de5a6`

Dataset:

- ETTh1
- canonical ETT release
- 17,420 observations
- 7 forecasting variables
- hourly sampling

Experiment configuration:

- model: DLinear
- feature mode: M
- sequence length: 336
- forecast horizons: 96, 192, 336, 720
- encoder channels: 7
- individual: False
- moving average: 25
- batch size: 32
- learning rate: 0.005
- loss: MSE
- execution: CPU

All four forecast horizons completed successfully.

The reproduced and published MSE/MAE values are stored in:

`results/original_replication.csv`

Derived absolute and percentage differences are generated by:

`src/evaluate_results.py`

This initial experiment is evidence of executable replication progress.
It is not treated as a reproduction of the complete paper.
